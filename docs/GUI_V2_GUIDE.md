# Edge TTS GUI v2 - 美化版使用指南

##  全新美化界面

全新的现代化界面设计,更加美观易用!

## ✨ 新功能特性

### 1. 📁 文本文件列表(左侧面板)
- **指定文本目录**: 选择包含txt文件的目录
- **自动扫描**: 自动读取目录下所有.txt文件
- **文件列表**: 显示所有找到的文本文件
- **快速操作**:
  - 单击选择并预览
  - **双击文件**直接开始转换
- **刷新按钮**: 🔄 重新扫描目录

### 2. 📖 文本预览(中间面板)
- **实时预览**: 选择文件后自动显示内容
- **文件名显示**: 显示当前预览的文件名
- **统计信息**: 显示字数和预计时长
- **滚动查看**: 支持长文本滚动浏览

### 3. ⚙️ 语音设置(右侧面板)
- **语音选择**: 下拉菜单选择15+种中文语音
- **语速调节**: 正常/加快/减慢
- **音量调节**: 正常/增大/减小
- **输出目录**: 选择音频保存位置
- **自动命名**: 输出文件名与输入文件一致

### 4. 🎵 播放控制
- **一键播放**: 转换完成后自动播放
- **播放/停止切换**: 同一个按钮切换状态
- **播放中**: 按钮变为"⏹️ 停止播放"(红色)
- **播放完成**: 自动恢复为"▶️ 播放音频"(黄色)
- **防止重复**: 点击停止后才能再次播放

##  使用方法

### 启动程序

```bash
./run.sh edge_tts_gui_v2.py
```

或直接运行:

```bash
python edge_tts_gui_v2.py
```

### 操作流程

#### 方式一: 完整流程

1. **选择文本目录**
   - 点击"📂 浏览"按钮
   - 选择包含.txt文件的目录
   - 点击"🔄"刷新按钮加载文件列表

2. **预览文本**
   - 在左侧列表中单击文件
   - 中间面板显示文件内容
   - 查看字数和预计时长

3. **调整设置**
   - 选择喜欢的语音
   - 调整语速和音量

4. **开始转换**
   - 点击"🎤 开始转换"按钮
   - 等待转换完成
   - 自动播放生成的音频

#### 方式二: 快速转换

1. 选择文本目录并加载文件列表
2. **双击**要转换的文件
3. 自动开始转换并播放

## 💡 使用技巧

### 批量处理

1. 选择包含多个txt文件的目录
2. 依次双击每个文件
3. 每个文件会自动转换为同名mp3

### 预览大文件

- 使用鼠标滚轮或滚动条查看长文本
- 字数统计帮助预估语音时长

### 播放控制

- **播放中**: 点击"️ 停止播放"停止
- **播放后**: 点击"▶️ 播放音频"重新播放
- **防止重复**: 必须停止后才能再次播放

### 文件管理

- 点击"📂 打开文件夹"查看输出文件
- 输出文件自动使用输入文件名
- 方便识别和整理

## ⚠️ 注意事项

### 文件要求

- 只支持.txt格式文本文件
- 文件编码: UTF-8
- 文件大小: 建议不超过10MB

### 播放器要求

程序会按顺序尝试以下播放器:
1. **mpv** (推荐)
2. **vlc**
3. **ffplay**

安装播放器:
```bash
# Ubuntu/Debian
sudo apt install mpv

# CentOS/RHEL
sudo yum install mpv

# macOS
brew install mpv
```

### 性能优化

- 大文件转换需要较长时间
- 可通过调整语速加快生成
- 建议分批处理超长文本

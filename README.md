# Edge TTS GUI - 文本转语音

基于微软Edge TTS的免费文本转语音工具，提供友好的图形界面。

##  特点

- ✅ **完全免费** - 基于Edge TTS，无需API密钥
- ✅ **无需注册** - 开箱即用
- ✅ **图形界面** - 友好的GUI操作
- ✅ **批量转换** - 支持同时转换多个文本文件
- ✅ **多种语音** - 17+种中文语音可选
- ✅ **可调节参数** - 语速、音量可调
- ✅ **双格式输出** - 支持MP3和WAV格式

## 🚀 快速开始

### 1. 运行GUI

```bash
./run.sh edge_tts_gui_v2.py
```

或直接运行：

```bash
python edge_tts_gui_v2.py
```

### 2. 使用步骤

```
1. 选择文本目录 → 自动加载目录下所有.txt文件
   ↓
2. 选择要转换的文件 → 默认全选，可单独选择
   ↓
3. 配置语音参数 → 选择发音人、语速、音量
   ↓
4. 选择输出格式 → MP3或WAV
   ↓
5. 点击"开始转换" → 批量转换选中的文件
   ↓
6. 在输出列表中播放 → 点击音频文件名即可播放
```

## 📋 界面功能

### 左侧面板 - 文件管理
- **选择文本目录**: 选择包含.txt文件的目录
- **全选/取消全选**: 一键选择或取消所有文件
- **文件列表**: 显示目录下所有文本文件(复选框)
- **自动设置**: 输出目录自动设为输入文件所在目录

### 中间面板 - 文本预览
- **文件预览**: 点击复选框自动预览文件内容
- **文件信息**: 显示字数和预计时长

### 右侧面板 - 语音设置
- **语音选择**: 17+种中文语音(晓晓、云希等)
- **语速调整**: 正常/加快/减慢
- **音量调整**: 正常/增大/减小
- **输出目录**: 自动匹配输入文件目录，也可手动设置
- **输出格式**: MP3 / WAV格式选择
- **操作按钮**: 开始转换、播放音频、打开文件夹
- **输出列表**: 显示所有生成的音频文件，点击即可播放
- **播放进度**: 可视化播放进度条

## 📦 安装依赖

### 自动安装(推荐)

```bash
./run.sh edge_tts_gui_v2.py
```

运行脚本会自动：
- 创建虚拟环境
- 安装所需依赖
- 运行GUI程序

### 手动安装

```bash
# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate  # Linux/Mac
# 或 venv\Scripts\activate  # Windows

# 安装依赖
pip install edge-tts

# 运行GUI
python edge_tts_gui_v2.py
```

## 💡 使用技巧

### 1. 文件命名规范
- 使用有意义的文件名(如 chapter1.txt, chapter2.txt)
- 输出文件会自动使用相同的文件名(如 chapter1.mp3)

### 2. 批量处理
- 将多个文本文件放在同一目录
- 全选后一次性转换
- 输出文件自动保存到同目录

### 3. 格式选择
- **MP3**: 文件较小，适合网络传输
- **WAV**: 无损音质，适合后期处理

### 4. 语音推荐
- 👩 **晓晓**: 温柔女声(默认)
- 👨 **云希**: 沉稳男声
- 👧 **晓双**: 儿童女声
- 👦 **云野**: 活泼男声

## ❓ 常见问题

### Q1: 界面打不开？

**A**: 确保已安装依赖：
```bash
pip install edge-tts
```

tkinter是Python标准库，通常已内置。

### Q2: 转换失败？

**A**: 检查：
- 网络连接是否正常
- 文本是否为空
- 输出目录是否有写入权限

### Q3: 无法播放？

**A**: 
- 确保系统安装了音频播放器(mpv/vlc/ffplay)
- Linux用户可安装: `sudo apt install mpv`
- 或手动用其他播放器打开文件

### Q4: 如何选择部分文件转换？

**A**: 
- 在文件列表中，取消不需要转换的文件复选框
- 点击"全选/取消全选"按钮快速选择

### Q5: 支持其他语言吗？

**A**: 
当前版本主要针对中文优化。如需其他语言，可以修改代码中的语音列表。

### Q6: Edge TTS稳定吗？

**A**: 
相对稳定，依赖微软服务。如果遇到问题，建议：
- 检查网络连接
- 稍后重试
- 查看网络问题排查文档
